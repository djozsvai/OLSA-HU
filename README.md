# OLSA-HU
Development and validation of the Hungarian Matrix Sentence Test

This is an effort to create the Hungarian adoption of the Oldenburg five-word matrix sentence test. The test is intended to help assess hearing in noise (SIN). The matrix contains 10x5 words that are selected so that they represent the phonemic landscape of the spoken Hungarian language as reported by Beke et al [1]. 

References:
[1]: Beke et al.: Gyakorisági vizsgálatok spontán beszédben (2012)
